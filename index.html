Agent crew

invideo — AI Video Creation Platform

An idea, a script or a link goes in; a finished, publish-ready video comes out. A crew of Claude-powered agents — Director, Scriptwriter, Cinematographer, Casting, Character Designer, Colorist, Sound, Music, Brand Safety and QC — is assembled per project and runs the production end to end.

  • Ten-stage pipeline you can see and stop. Script, Safety, Casting, Storyboard, Visuals, Animate, Voiceover, Music, Sound, Edit & render — each stage re-runnable on its own, each able to pause for review before it spends anything.
  • The bill before the run. Every stage carries a credit cost, and the panel shows estimated spend, the typical range, the current balance and what the balance would be afterwards — including when that number goes negative.
  • Character consistency that is auditable. Recurring subjects are locked once and reused verbatim, with a seed lock, a consistency score across shots, and branch signatures showing exactly which routings each description was sent to.
  • Nothing regenerates silently. Editing a character sheet changes future generations only; the storyboard tracks per-shot revision drift, stale frames and image/motion QC.
  • Style is configuration, not a rebuild. The same ten stages produce hand-drawn doodle, documentary photorealism or UGC phone-selfie footage — platform, length, language, style and consistency mode are settings on the run.
  • Model routing across providers — one family for the reasoning stages, others for image, video and speech — swappable per run, with an opt-in paid fallback if the free provider is down.
  • Verified by integration suites against real containerised dependencies, plus architecture-boundary and contract tests that fail the build, on every pipeline.

CLIPPER — Automated Video Clipping Factory

Long-form video in, short vertical publish-ready clips out. Nine specialised agents run the chain, and every clip comes out scored on how likely it is to hold a viewer — with the reasoning shown.

VideoIngest→ whisper→ Scout→ BrandSafety→ CutPlanner→ SubjectReframe→ libass→ Publicist→ ffmpeg
  • A retention score that explains itself. Hook, Pace, Payoff and Loop are scored separately with the evidence attached — “payoff tease lands inside 2 s”, “3.7 w/s · 4 gaps (4.6 s dead air pre-strip)” — not a single opaque number.
  • It closes the loop with reality. Paste a platform's real stats for a published clip and they are parsed into a calibration set; once twenty clips land, the scoring weights refit against measured performance instead of staying a guess.
  • It admits what it does not know. Loop scores 0/20 and is labelled “not yet measured”; the retention curve is labelled “model, not a measurement”; the dashboard states every figure is a query over existing tables, zero fabrication.
  • Nothing is destroyed. Every re-caption or restore creates a new take rather than overwriting — a decision recorded as an ADR and surfaced in the UI.
  • Reframe, caption and aspect are choices, not re-runs — subject-track / two-shot / center-crop, four caption presets, 9:16 / 1:1 / 16:9, each producing a fresh take.
  • Per-role model routing, steered in plain English. Strategist, Highlight Scout, Editor, Publicist and QC each run on their own model — Opus where judgement is expensive, Haiku where it isn't — and each takes a written brief (“keep hooks under six words”) fed in as a directive rather than a code change. Old runs keep their crew snapshot, so changing a brief never rewrites history.
  • Nothing reaches a platform unreviewed. Publishing runs through a chain — CLASSIFY, MATCH, CLEAR, LOCALIZE, ROUTE, QUEUE — that stops at a gate before anything goes out, switchable per source between manual and automatic.
  • Cost attributed per stage, with a one-approve review queue between proposal and publish.

Kirim — Encrypted Messenger

A WhatsApp-class messenger built end to end: a multi-module native mobile client against a natively-compiled backend, with a socket carrying binary frames generated from the same contract the backend compiles.

  • End-to-end encryption on an audited protocol library — identity and pre-key vaults, per-peer session stores, safety numbers, a separate media cipher, and the identity key sealed in the platform keystore.
  • A nightly two-emulator CI gate proves one message becomes one ciphertext per device.
  • A declarative UI layer over compile-time dependency injection, with the local database as single source of truth; minified and lint-gated on every build.
